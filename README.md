# 🛒 Customer Purchase Prediction Project

##  Overview
Machine Learning project using Decision Tree to predict whether a customer will purchase a product based on browsing behavior.

---

##  Dataset
Online Shoppers Purchasing Intention Dataset (UCI)

---

##  Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Streamlit
- Matplotlib, Seaborn

---

##  How to Run

### 1. Install dependencies
pip install -r requirements.txt


### 2. Train model

python train_pipeline.py


### 3. Run Streamlit app

streamlit run app/streamlit_app.py


---

## 🌐 App Features
- Customer Purchase Prediction
- Real-time input
- Model probability output
- Feature engineering included
